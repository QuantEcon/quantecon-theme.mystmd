# QuantEcon Book Theme for MyST

The QuantEcon book theme, in the Manuscript direction: Newsreader serif with
IBM Plex Mono labels, warm paper in light and dark, a breadcrumb of
dropdowns (Part › Chapter › Section) over a hidden contents drawer, and a
right gutter for margin notes.

Source, documentation and releases:
https://github.com/QuantEcon/quantecon-theme.mystmd (`themes/book`; releases
tagged `book-vX.Y.Z`, asset `quantecon-theme-book.zip`).
