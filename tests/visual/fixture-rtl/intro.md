این صفحه ویرایش راست‌به‌چپ قالب را می‌آزماید: متن *تأکیدی*، متن **پررنگ**، `کد درون‌خطی` و یک معادلهٔ درون‌خطی $e^{i\pi} + 1 = 0$ که باید چپ‌به‌راست بماند.

## کد

بلوک کد چپ‌به‌راست می‌ماند و دکمهٔ کپی در لبهٔ راست آن:

```python
import numpy as np

def f(x, scale=1.0):
    # توضیح به فارسی درون کد
    return scale * np.exp(-x ** 2)

print(f(np.linspace(0, 1, 3)))
```

## ریاضیات

$$
\int_{-\infty}^{\infty} e^{-x^2}\,dx = \sqrt{\pi}
$$
